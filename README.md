# Major Incident Tracker

A web-based Major Incident management dashboard built to support enterprise IT operations, aligned with ITSM best practices including incident lifecycle management, Root Cause Analysis (RCA), trend reporting, and stakeholder communications.

## Features
- Incident Dashboard with real-time P1/P2/P3 tracking and MTTR metrics
- RCA Manager with corrective action tracking
- Trend Analysis with incident volume and system MTTR charts
- Stakeholder Communications Log

## Usage
Open index.html in any browser — no build step required.

## Skills Demonstrated
- Major Incident lifecycle management
- Root Cause Analysis (RCA) facilitation
- MTTR and incident trend metrics
- Stakeholder communication structuring
- ITSM process documentation
